# Canvas

The desktop shell of **CanOS**, built with Quickshell for Hyprland.

- Living Island: clock, music, volume, brightness, workspaces, notifications
- Control Center, app launcher, theme switcher, power menu
- Area screenshots, clipboard history, lock screen with idle lock
- Live wallpaper, glass look, colors generated from the theme (matugen)
- Welcome app on first start
- English and German (`core/Lang.qml`)

## Run

```
bin/canvas start
```

## Commands

`canvas start|stop|restart|log` · `canvas launcher|themes|center|settings|power|clipboard|screenshot|lock|welcome` · `canvas theme <name>`

Suggested Hyprland keybinds:

| Keys | Command |
| --- | --- |
| Super + Alt + D | `canvas launcher` |
| Super + T | `canvas themes` |
| Super + V | `canvas clipboard` |
| Print | `canvas screenshot` |
| Super + L | `canvas lock` |
| Super + Esc | `canvas power` |

## Themes

A theme is a folder with a `theme.json` (`name`, `color`) and a `lock.png` wallpaper; `wallpaper.mp4` (live wallpaper) is optional.
Canvas looks in `~/.local/share/canvas/themes` first, then in `themes/` next to the shell.

The bundled themes are generated by `tools/make-wallpapers.py` and released under CC0.

## Dependencies

quickshell, hyprland, matugen, grim, wl-clipboard, cliphist, brightnessctl, cava, networkmanager, bluez-utils, libnotify
